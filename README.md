# HA 3D Home · 项目展示页

[HA 3D Home](https://github.com/sunhuipeng/ha-3d-home) 的单页介绍网站：把一个「轻量级 Home Assistant 3D 全屋智能控制中心」讲清楚——它能做什么、长什么样、怎么用插件扩展。

纯静态 HTML / CSS / JavaScript，无构建、无依赖、无 CDN，双击 `index.html` 就能打开，也可以直接丢到 GitHub Pages。

## 这个页面解决什么问题

一个开源项目通常只有 README 和几张截图，访客很难在 30 秒内理解它到底特别在哪。这个页面用一条完整的叙事线回答三个问题：

1. **它能做什么**——首屏一句话 + 三枚亮点徽章（全插件化 / 立体房屋背景 / 实体实时驱动）；
2. **用起来是什么感觉**——页面内嵌一个用 CSS 3D 复刻的大屏模型，可以拖拽转视角、长按改旋转锚点、点设备开关灯、切楼层和背景、一键执行场景，不需要安装任何东西；
3. **它是怎么做的**——面向开发者的架构图、三类插件的分工、生命周期代码示例、模型绘制方式、目录结构。

同时照顾两类读者：普通用户看前半段（`互动演示` / `小白上手` / `界面拆解`），开发者直接跳到 `开发者` 与 `插件库`。

| 区块 | 内容 |

## 目录结构

```
ha3d-site/
├── index.html          # 全部内容与文案
├── css/style.css       # 全部样式（亮色主题，含 3D 演示动画）
├── js/
│   ├── main.js         # 页面交互：轮播、标注联动、页签、数字滚动、插件筛选
│   └── demo.js         # 演示大屏：CSS 3D 场景构建、拖拽视角、设备与场景状态
├── assets/             # 5 张 WebP 截图
└── README.md
```

## 本地预览

直接双击 `index.html` 即可。若想走 HTTP（更接近线上环境）：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 部署

纯静态站点，把整个目录推到仓库后开启 GitHub Pages（Source 选分支根目录）即可，无需任何构建步骤。

页面内部所有资源都用相对路径，因此放在子目录（如 `https://用户名.github.io/仓库名/`）也能正常工作。

## 想改内容时看哪里

| 想改的东西 | 位置 |
| --- | --- |
| 文案、标题、插件卡片 | `index.html` |
| 配色、间距、圆角 | `css/style.css` 顶部的 `:root` 变量 |
| 首屏轮播截图 | `index.html` 中 `.carousel` 里的 `.c-slide`，图片放 `assets/` |
| 演示大屏的户型、家具、设备 | `js/demo.js` 顶部的 `PLAN` / `FURN` / `floors` |
| 页面交互行为 | `js/main.js` |

改动 CSS 或 JS 后记得同步 `index.html` 里引用末尾的版本号（`style.css?v=2026xxxx`），否则浏览器可能继续用缓存。
